# AI Safety, Grounding, and Retrieval Guardrails Whitepaper
Author: Research Architecture Team
Security Classification: Public Technical Report

## 1. Grounded Generation and Hallucination Mitigation
Grounded generation systems anchor large language model completions strictly to retrieved documentary evidence.
Extrinsic hallucinations occur when a model introduces non-factual statements absent from source documents.
To prevent fabrication, the retrieval pipeline applies a two-stage relevance gating filter.
Candidate chunks with cosine similarity below the calibrated threshold of 0.20 are discarded before generation.
When the retrieved evidence set is empty, the system returns a deterministic unanswerable response rather than speculating.

## 2. Citation Attribution and Source Tracing
Every factual claim generated by the system must include an inline provenance citation.
Citations specify the exact source document filename and page number: [Source: filename, Page N].
Automated citation audits cross-reference extracted claims against source spans using exact substring or semantic entailment checks.
Fabricated citations are treated as critical security anomalies and trigger audit logging alerts.

## 3. Prompt Injection Defense
Direct and indirect prompt injections are mitigated through structural delimiter isolation.
User inputs and retrieved external documents are passed into designated XML/Markdown boundaries.
System instructions explicitly command the model to ignore executable instructions or persona overrides embedded within retrieved chunks.
Tool calling is restricted to whitelisted functions with strict Pydantic input parameter validation.
